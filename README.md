# Hi, I'm Alex 👋

Aspiring QA Engineer based in Germany, focused on manual testing of web and mobile applications.

### 👨‍💻 About me:

I am building hands-on QA skills through practical assignments and personal portfolio projects. I focus on understanding product requirements, finding defects, documenting results clearly, and improving the quality of digital products.

### 🎯 Skills I am developing:

- Manual functional and exploratory testing
- Test cases, checklists, and bug reports
- Web testing with Chrome DevTools
- API testing with Postman
- Basic SQL and database testing
- Git, GitHub, and Bash for version control and command-line work
- Mobile application testing fundamentals

### 🤖 AI-assisted QA workflows:

I use ChatGPT as a learning and productivity assistant to analyse requirements, generate test ideas, improve test documentation, and explore edge cases. I validate all suggestions independently before using them in testing work.
